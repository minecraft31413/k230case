# K230 外壳 / K230 Enclosure

适用于 **立创·庐山派 K230 开发板（带屏幕版）** 的 3D 打印外壳。

## 适用硬件

- 板卡：立创·庐山派 K230 开发板（带屏版本）
- 说明：外壳按带屏版本的开孔与避让设计

## 文件说明

| 文件 | 格式 | 说明 |
| --- | --- | --- |
| `K230-case.SLDPRT` | SolidWorks 零件 | 外壳模型源文件，用 SolidWorks 打开 |

> 如需 STL / STEP 等通用格式，请在 SolidWorks 中「文件 → 另存为」选择对应格式导出。

## 打印建议

> 以下为参考参数，请根据自己的打印机与需求调整。

- 材料：PLA / PETG
- 层高：0.2 mm
- 填充：15% – 20%
- 墙层：3 层
- 支撑：按摆放方向决定
